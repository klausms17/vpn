# Klaus VPN — инструкция

Собственный VPN-клиент для Android на самом свежем ядре **Xray** (то же ядро, что в Happ
и v2rayNG). Вставляете ключ → нажимаете кнопку → подключено. Российские сайты и
приложения работают напрямую, остальное — через VPN.

## 1. Установка приложения

1. Откройте на телефоне страницу **Releases** репозитория (github.com/klausms17/vpn → Releases).
2. Скачайте файл:
   - `KlausVPN-…-arm64-v8a.apk` — для почти всех современных телефонов;
   - `KlausVPN-…-armeabi-v7a.apk` — для старых 32-битных;
   - `KlausVPN-…-universal.apk` — если не уверены (подходит всем, но больше).
3. Откройте файл и разрешите установку из этого источника.

## 2. Сервер

Нужен VPS за границей (Нидерланды, Германия, Финляндия и т. п.): 1 ядро, 1 ГБ ОЗУ,
Ubuntu 24.04 или Debian 12. Репозиторий приватный, поэтому скрипт копируется вручную:

1. Откройте на GitHub файл `server/install.sh` (ветка `claude/compassionate-mayer-6jph8m`,
   пока работа не перенесена в `main`) → кнопка **Raw** → скопируйте весь текст.
2. Подключитесь к серверу по SSH и выполните `nano install.sh`, вставьте текст,
   сохраните (Ctrl+O, Enter, Ctrl+X).
3. Запустите:

```bash
sudo bash install.sh
```

Скрипт сам:
- поставит последнюю версию Xray;
- создаст ключи и настроит **VLESS + REALITY + Vision** на порту 443 (основной, самый быстрый)
  и резервный **VLESS + REALITY + XHTTP** на порту 8443;
- подберёт сайт для маскировки (проверяет, что он работает по TLS 1.3);
- включит BBR (заметно быстрее на дальних и нестабильных каналах);
- выведет готовые ключи и QR-код, а также сохранит их в `/root/klausvpn-keys.txt`.

Повторный запуск **не меняет ключи** (так же обновляется Xray). Параметры пишутся **после** `sudo`:

- новые ключи (старые перестанут работать): `sudo RESET=1 bash install.sh`;
- свой сайт для маскировки: `sudo SNI=www.example.com bash install.sh`.

Если на сервере уже есть настройки Xray, сделанные не этим скриптом, он остановится и ничего
не тронет. Заменить их: `sudo FORCE=1 bash install.sh` (старая настройка сохранится копией).


## 3. Добавление ключа

Нажмите **«+»** и вставьте ключ (`vless://`, `vmess://`, `trojan://`, `ss://`, `hy2://`) или
ссылку на подписку (`https://…`). Можно вставить сразу несколько ключей, по одному на строке.
Ещё проще — в мессенджере нажать «Поделиться» на сообщении с ключом и выбрать Klaus VPN.

Кнопка «Проверить все» измеряет реальную задержку до каждого сервера (через сам VPN-протокол,
а не простой ping).

## 4. Что идёт через VPN

Настраивать ничего не нужно: российские сайты и сервисы (.ru/.рф/.su, Госуслуги, банки,
Яндекс, VK, Ozon, WB и все российские IP) работают напрямую, остальное — через VPN.

Списки российских сайтов берутся из проекта runetfreedom (обновляется каждые 6 часов).
Свежая копия вшивается в каждую сборку приложения, а в настройках есть пункт
«Обновить списки» (раздел «Если что-то не работает»).

## 5. Российские приложения без VPN

Многие банки, Госуслуги и маркетплейсы ругаются или не работают, когда видят VPN. Переключатель
**«Российские сервисы»** (Настройки → «Приложения без VPN», включён по умолчанию) полностью
выводит их из туннеля — они работают как без VPN. Список можно дополнить: там же
«Другие приложения». Браузеры в этот список специально не входят.

## 6. Белые списки мобильного интернета

При ограничениях мобильной связи работают только одобренные (в основном российские) адреса,
и любой зарубежный сервер становится недоступен. Приложение показывает отметку
**«белый список»** у серверов, чей IP в этот список входит (данные runetfreedom).

Обходной путь — промежуточный сервер в России с IP из белого списка, который пересылает
трафик на ваш зарубежный сервер:

```bash
# install-relay.sh копируется на российский сервер так же, как install.sh
sudo UPSTREAM='vless://…ключ основного сервера…' bash install-relay.sh
```

Скрипт выдаст ключ ретранслятора — добавьте его в приложение как ещё один сервер.

## 7. Надёжность и батарея

- **Постоянный VPN**: Настройки → «Постоянный VPN» → включите «Постоянная VPN». Тогда VPN сам
  поднимется после перезагрузки.
  «Блокировать соединения без VPN» **не включайте**: Android тогда отключает интернет всем
  приложениям, которые работают без VPN, — банкам, Госуслугам, маркетплейсам. Если всё же
  включили, приложение предупредит об этом в уведомлении.
- **Работа в фоне**: на Xiaomi, Huawei, Honor, Samsung, Realme разрешите приложению работать
  без ограничений батареи (Настройки → «Работа в фоне»), иначе прошивка может его выгрузить.
- Приложение ничего не делает в фоне само по себе: нет таймеров, опросов и фоновых проверок.
  Трафик не подсчитывается; таймер подключения идёт, только пока открыт экран приложения.
- Если что-то не так: Настройки → «Сообщить о проблеме» — там журнал и кнопка «Копировать».
  В журнале могут быть адреса серверов, поэтому пересылайте его только тому, кому доверяете.

## 8. Что сделано для стабильности и безопасности

| Типичная проблема самодельных VPN | Как решено |
|---|---|
| Трафик ядра зацикливается в собственный туннель | Приложение всегда исключено из своего туннеля |
| Открытый локальный SOCKS/HTTP-порт — по нему приложения вычисляют VPN и IP сервера | Никаких локальных портов: ядро читает TUN напрямую |
| Утечки DNS и подмена DNS провайдером | Все DNS-запросы отвечает ядро: российские домены — через Яндекс DNS напрямую, остальные — через DoH внутри VPN |
| Утечка IPv6 мимо VPN | Весь IPv6 заводится в туннель; при выключенном IPv6 такие соединения сразу отклоняются |
| «Зависание» мессенджеров при смене Wi-Fi ↔ LTE | Соединения пересоздаются сразу после смены сети |
| Утечка при смене сервера | Новый туннель поднимается до закрытия старого |
| Падение интерфейса роняет VPN | VPN работает в отдельном процессе |
| Бесконечные перезапуски при сбое | Не более 3 автоперезапусков за 5 минут, дальше — уведомление |
| Ключи попадают в облачные бэкапы | Бэкапы отключены полностью |
| Ключ виден в истории буфера обмена | Скопированный ключ помечается как секретный (Android 13+) |
| Старые ключи с `allowInsecure` перестали работать в новом Xray | Сертификат сервера автоматически закрепляется при добавлении |
| Новые REALITY-серверы отвергают старые «отпечатки» браузера (ios, edge и т. п.) | Несовместимый отпечаток автоматически заменяется на chrome |
| Устаревшие транспорты (HTTP/2, QUIC, XTLS) | Понятное сообщение при добавлении ключа, а не тихая неработоспособность |
| Нерабочий файл баз после загрузки | Базы проверяются перед заменой, замена атомарная |

Почему ваш ключ работал в Happ, но не в v2RayTun: свежий Xray-сервер с REALITY принимает
только клиентов, предлагающих постквантовый обмен ключами (X25519MLKEM768). В старых сборках
ядра этого нет — сервер молча отбрасывает такие подключения. В Klaus VPN — ядро сентября 2026.

## 9. Подпись приложения (важно для обновлений)

Чтобы новые версии устанавливались поверх старых (без удаления и потери ключей), сборки
должны подписываться одним и тем же ключом. Один раз добавьте секреты в репозиторий
(GitHub → Settings → Secrets and variables → Actions → New repository secret):

| Секрет | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | файл ключа в base64 |
| `ANDROID_KEYSTORE_PASSWORD` | пароль ключа |

Создать ключ (на компьютере с Java):

```bash
keytool -genkeypair -keystore release.jks -alias release -keyalg RSA -keysize 4096 \
  -validity 36500 -dname "CN=Klaus VPN"
base64 -w0 release.jks   # это значение для ANDROID_KEYSTORE_BASE64
```

Храните `release.jks` и пароль в надёжном месте: без них обновить установленное приложение
будет нельзя. Пока секреты не добавлены, сборки подписываются временным ключом.

## 10. Сборка и проверки

Каждое изменение автоматически:
1. прогоняет тесты ядра, включая сквозные — поднимаются настоящие Xray-серверы 13 вариантов
   (VLESS REALITY Vision/XHTTP, постквантовое шифрование, TLS WS/gRPC/HTTPUpgrade, Trojan,
   VMess, Shadowsocks 2022, Hysteria2…) и через них гоняется реальный TCP и UDP трафик;
2. проверяет время старта и расход памяти ядра;
3. собирает ядро под Android, APK (с минимизацией R8), проверяет выравнивание библиотек 16 КБ
   и публикует тестовую сборку в Releases.

## 11. iPhone

Вся логика (разбор ключей и подписок, генерация конфигурации, правила для России) находится
в общем ядре `libxray/` и собирается для iOS той же командой (`gomobile bind -target=ios`).
Для iPhone останется сделать интерфейс и системный VPN-модуль (Network Extension).

## 12. Раздача знакомым: панель и подписки

Ключ из `install.sh` один на всех: его нельзя отключить одному человеку, а если сервер
заблокируют, новый ключ придётся рассылать каждому. Для раздачи знакомым есть панель
**Remnawave**: у каждого своя ссылка-подписка, по ней приложение само получает список
серверов и обновляет его. Сервер заблокировали — вы добавляете новый в панели, знакомым
ничего делать не нужно.

### Что купить

- **VPS для панели** за границей: 2 ядра, 4 ГБ ОЗУ, Ubuntu 24.04 или Debian 12. VPN на нём
  не работает — только панель и страница подписки.
- **VPS для VPN** (один или несколько) за границей, как в разделе 2. При безлимитном трафике
  главное — скорость канала и объём трафика в тарифе.
- **Домен** в зоне .com, .net, .org и т. п. Домены .ru, .su, .рф не подойдут: для них не
  выдают бесплатный сертификат HTTPS. В настройках DNS создайте две записи типа A на IP
  VPS панели, например `panel.example.com` (панель) и `sub.example.com` (подписки). Если
  домен в Cloudflare, выключите для этих записей проксирование (серое облако).

### Установка: три команды

Скрипты лежат в папке `server/remnawave/` и копируются на серверы так же, как `install.sh`
(раздел 2).

1. **Панель.** На VPS панели положите `install-panel.sh` и `klaus-panel` в одну папку и
   выполните:

   ```bash
   sudo PANEL_DOMAIN=panel.example.com SUB_DOMAIN=sub.example.com bash install-panel.sh
   ```

   Скрипт поставит Docker, панель, страницу подписки и Caddy (он сам получает и продлевает
   сертификаты HTTPS), создаст администратора и настроит всё для Klaus VPN: протокол
   VLESS + REALITY, название «Klaus VPN» в приложении, кнопку «Добавить в Klaus VPN» на
   странице подписки. Логин и пароль от панели — в `/root/remnawave-admin.txt`. Адрес
   панели знакомым не нужен, не показывайте его: им хватает ссылки на подписку.

   Дополнительно можно указать `APK_URL=https://…` — ссылку на файл приложения, которая
   открывается без входа (например, в облачном диске): на странице подписки появится кнопка
   «Скачать Klaus VPN». Своя ссылка для связи с вами: `SUPPORT_URL=https://t.me/…`.

2. **VPN-сервер.** На VPS панели:

   ```bash
   klaus-panel add-node de-1 203.0.113.10 DE
   ```

   (имя сервера латиницей, его IP и страна; название, которое увидят знакомые, можно задать
   так: `--title "Германия"`). Команда выведет готовую строку вида
   `sudo PANEL_IP=… SECRET_KEY='…' bash install-node.sh` — выполните её на VPS для VPN,
   скопировав туда `install-node.sh`. Скрипт поставит Docker и сервер Remnawave, включит BBR
   и откроет порт управления (2222) только для панели. Через минуту `klaus-panel list-nodes`
   покажет «на связи».

3. **Знакомый.** На VPS панели:

   ```bash
   klaus-panel add-user masha
   ```

   Команда выведет личную ссылку `https://sub.example.com/…`, QR-код и ссылку
   `klausvpn://add/…`, которая сразу открывает приложение. Ссылку отправляйте лично: по ней
   любой может пользоваться VPN.

Повторный запуск `install-panel.sh` или `install-node.sh` ничего не ломает: ключи,
пользователи и пароли сохраняются, а программы обновляются до последних версий.

### Как знакомому подключиться

1. Открыть ссылку на телефоне. Откроется страница подписки с инструкцией.
2. Установить Klaus VPN (кнопка «Скачать Klaus VPN», если вы указали `APK_URL`, или файл от
   вас — раздел 1).
3. Нажать **«Добавить в Klaus VPN»**: приложение откроется и предложит добавить подписку.
   Если ничего не произошло (так бывает во встроенном браузере Telegram), нажать
   «Скопировать ссылку», открыть Klaus VPN, нажать **«+»** и вставить. Можно и просто
   прислать ему ссылку сообщением и «Поделиться» ею в Klaus VPN.
4. Нажать большую кнопку. Дальше список серверов приложение обновляет само.

### Если сервер заблокировали

Купите новый VPS и выполните на панели:

```bash
klaus-panel add-node nl-1 198.51.100.20 NL    # и установите его, как в шаге 2
klaus-panel disable-node de-1                 # старый уходит из подписок
```

Знакомым ничего делать не нужно: приложение получит новый сервер при обновлении подписки.
Все серверы работают с одними и теми же ключами, поэтому ссылки не меняются.
`klaus-panel enable-node de-1` вернёт сервер обратно.

### Другие команды

| Команда | Что делает |
|---|---|
| `klaus-panel list-users` | все знакомые: включён ли, сколько устройств, трафик, когда был в сети |
| `klaus-panel link masha` | снова показать ссылку и QR-код |
| `klaus-panel disable-user masha` | отключить (подписка и VPN перестают работать), `enable-user` — вернуть |
| `klaus-panel delete-user masha` | удалить совсем |
| `klaus-panel list-nodes` | серверы: на связи ли, сколько человек онлайн |
| `klaus-panel help` | все команды |

Всё это же можно делать в самой панели: `https://panel.example.com`.

### Резервная копия

```bash
klaus-panel backup
```

Сохраняет базу (знакомые, их ссылки, серверы, ключи) и настройки в
`/root/remnawave-backups/klausvpn-panel-….tar.gz`. Скачайте файл к себе
(`scp root@IP-панели:/root/remnawave-backups/*.tar.gz .`) и храните как пароль: в нём все
ключи. Без копии при потере VPS панели всем придётся выдать новые ссылки и заново
установить серверы.

Переезд панели на новый VPS: положите рядом `install-panel.sh`, `klaus-panel` и архив и
выполните `sudo RESTORE=klausvpn-panel-….tar.gz bash install-panel.sh`. Затем направьте оба
домена на новый IP и на каждом VPN-сервере выполните `sudo PANEL_IP=новый-IP bash install-node.sh`.
Ссылки знакомых не меняются.

### Лимит устройств (включается потом)

Панель уже записывает, с каких телефонов открывают подписку (столбец «устройств» в
`klaus-panel list-users`), но пока ничего не ограничивает. Включайте лимит, только когда:

1. у всех знакомых стоит версия Klaus VPN, которая сообщает панели устройство (у каждого в
   `list-users` есть хотя бы одно устройство — иначе он сразу потеряет серверы);
2. сборки подписаны постоянным ключом (раздел 9): со временным ключом каждая новая версия
   приложения выглядит как новое устройство.

```bash
klaus-panel hwid-limit 3                  # 3 устройства на человека
klaus-panel add-user papa --devices 5     # новому знакомому — свой лимит
klaus-panel hwid-limit off                # выключить
```

Поменять лимит уже добавленному человеку или удалить его старый телефон, чтобы освободить
место: панель → «Пользователи» → имя → устройства.

### Переход со старых ключей

- Проще всего поставить VPN-сервер панели на **новый** VPS: старый сервер из `install.sh`
  работает дальше, пока все знакомые не перейдут на подписки.
- На том же VPS `install-node.sh` не запустится, пока работает старый Xray (порт 443 занят).
  Когда все перешли, выполните `sudo MIGRATE=1 PANEL_IP=… SECRET_KEY='…' bash install-node.sh`:
  старый Xray выключится, и старые ключи перестанут работать.
- Ретранслятор из раздела 6 (`install-relay.sh`) работает с одним общим ключом и в подписки
  не входит.
