Запуск

Журнал

В журнале нет ключей, адресов и названий сайтов: его можно отправить тому, кто помогает с VPN.

Аккаунт

С аккаунтом VPN работает на всех ваших устройствах: телефоне, компьютере, iPhone и Mac. Войдите с одной почтой, и серверы появятся сами, без ссылок и ключей. Забыли пароль — восстановите его по почте. Без аккаунта всё работает как раньше.

Новый пароль — не короче 8 символов.

Подтвердите почту

Аккаунт удалится насовсем, а его серверы пропадут со всех устройств. Введите пароль, чтобы подтвердить.

О программе

Kirov VPN для Windows

Ключи, подписки и настройки хранятся только на этом компьютере, в зашифрованном виде. Kirov VPN не записывает, какие сайты вы открываете.

Kirov VPN работает на ядре Xray. Флаги стран — circle-flags. Тексты лицензий — в папке программы, licenses.
